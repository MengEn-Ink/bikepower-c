# BikePower 核心设备门户高保真原型

入口：`index.html`

这是基于 `docs/dev/15-core-portal-rewrite-design.md` 的交互设计稿，不连接固件后端。

可操作内容：

- 骑行 / 跑步切换。
- 默认沿用模拟输出；用户主动选择真实功率计后再渐进披露桥接配置。
- 功率计扫描、选择与测试。
- 首次接入真实功率计后心率默认关闭，可自行开启；更换功率计不覆盖手动选择。
- 显示功率计名称、厂商、型号、序列号及硬件/固件/软件版本（均为示例数据）。
- 可勾选复制设备信息，名称支持使用功率计名称、保留开发板名称或自定义；预览后保存应用。
- 原值、固定瓦数、百分比校正。
- 广播数据项、模拟心率和算法参数。
- 设备名、按钮步进与固件详情。
- 草稿、保存、关闭 WiFi 和运行异常状态。

桥接披露顺序：

1. 默认只显示旧版模拟配置。
2. 选择“真实功率计”后只显示选择设备入口。
3. 测试通过后展示设备、校正、真实踏频和桥接相关配置。
4. 保存后实际输出才切换为真实桥接。

验证视口：`1440×900`、`390×844`、`375×812`。

手机入口：`mobile-prototype.html`，内联全部样式和交互代码。采用旧版高密度布局，实时指标并排、参数双列、分段控件横排。通过 Chromium 验证；未验证 Safari。

复制仅针对名称和 DIS 字段，不复制蓝牙地址，不创建模板库；未提供的字段保留开发板原值。复制完成后即使切回模拟模式也保留已保存的身份信息。

第二版离线文件：`mobile-prototype-v2.html`；上一版保存在 `mobile-prototype-v1.html`。

- 所有按钮文案居中，点击提供轻量反馈。
- 配网倒计时默认 5 分钟，续期恢复至 5 分钟；按照真实经过时间更新，页面切到后台后不会人为延长。
- 模拟输出统一为固定功率 / 配速机器人两项。自定义作为机器人的强度选项，与预设共用体重、踏频和功率范围预览。
- 模式面板和弹窗使用 200–240ms 的淡入位移动画；系统开启减少动态效果时关闭动画。
