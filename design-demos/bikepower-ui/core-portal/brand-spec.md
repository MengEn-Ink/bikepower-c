# BikePower 设备门户品牌规范

## 标识

使用当前设备门户已有的 BikePower 图形标和文字标：

- 图形：开口圆环、闪电和轮毂。
- 文字：`BikePower`，不增加新副品牌。
- 原型内用内联 SVG，避免外部资源。

## 字体与几何

- 字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif`。
- 数字：系统等宽数字特性。
- 圆角：按钮 7px，面板 8px，输入 6px。
- 阴影仅用于模态层，不用于普通页面区段。
- 所有交互控件最小 44px。
