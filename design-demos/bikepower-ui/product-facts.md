# BikePower UI · Product Facts

> 核对日期：2026-10-27。事实来自本仓库源码、技术文档与本轮真机验收，不把设计示例值表述成设备实测值。

## 产品与版本

- 产品：BikePower C，ESP32-C3 + ESP-IDF + NimBLE 固件。
- 当前固件：v4.1.3；本轮真机验收绑定 Git `749d7d9`。
- 运动 profile：cycling / running；本次页面设计聚焦 cycling，running 不删除但不抢首屏。

## 监控页面现有能力

- Web Serial 固件刷写与固件元信息查看。
- Web Bluetooth 扫描、授权设备重连、DIS 信息读取、GATT 服务枚举。
- CPS / HRS / CSC / RSC / FTMS 通知订阅与实时功率、心率、踏频/步频、速度显示。
- 通知停更、BLE 断连、功率/心率/踏频/速度越界、解析错误的异常记录。
- 保存设备模板、多设备比对、JSON 报告导出、事件日志。
- Web Bluetooth 首次授权必须由用户点击；不能设计成静默自动连接。

## 骑行端配置页现有能力

- 骑行/跑步切换，以及功率、踏频、心率广播项开关。
- 骑行功率来源、固定功率、W/kg 机器人、功率/踏频/心率浮动。
- 心率联动/锁定，FTMS ERG 控制状态提示。
- 用户体重、FTP、阈值心率；设备广播名；模板；物理按钮步进；LED 灯效。
- 保存配置、保存并关闭 WiFi；配网剩余时间续期。
- WiFi 配网不能开机自启，必须由物理按钮长按与二次确认进入。

## 设计示例数据说明

方向稿里的 `258 W / 151 bpm / 89 rpm`、曲线和时间戳用于呈现信息层级与状态，并非当前开发板的新一轮采样结果。实现时继续接现有实时数据和 API。

## 外部方法核对

- Grafana 官方文档把 dashboard 定义为按行或标签组织的一组相关 panels，用于一眼理解相关信息；本项目借其“任务分组 + 面板层级”，不借其视觉皮肤。
- Wahoo 官方配对流程强调进入 Devices、选择 Pair sensor、选择目标设备、确认配对；本项目借其短路径，不假装绕过浏览器授权。
