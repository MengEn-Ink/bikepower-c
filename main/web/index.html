BikePower 是什么

BikePower 是一台 BLE 骑行数据模拟设备，可向 Zwift、TrainerRoad 等 App 广播功率、踏频和心率。

三种骑行模式

固定模式：按你设置的功率、踏频、心率输出，并在浮动范围内平滑变化。

配速机器人：按体重和所选功体比自动生成目标功率，模拟跟随虚拟骑手。

ERG 模式：骑行 App 下发目标功率时自动进入，设备跟随 App 的目标功率输出。

功率与心率

设备会先按 FTP 判断当前功率强度，再映射到阈值心率区间，并用平滑模型模拟心率上升和下降的惯性。

使用提醒

保存生效：修改后需点「保存设置」才会持久化。

关闭 WiFi：点「保存并关闭 WiFi」返回骑行模式，BLE 持续在线。

重新配网：长按设备按钮 2 秒，并在确认窗口内再按一次。
