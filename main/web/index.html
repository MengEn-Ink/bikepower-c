三种骑行模式

固定模式：功率/踏频/心率按你设定的基准值输出，可各自设置浮动范围模拟真实骑行的自然波动。

配速机器人：按所选档位功体比自动输出功率，模拟跟随虚拟骑手，无需骑行 App。

ERG 模式：骑行 App 下发目标功率时自动进入，设备锁定到 App 指定功率。

功率 → 心率 关联

真实骑行中心率随功率上升而上升，但存在滞后与惯性。本设备用生理模型还原这一关系，而非简单线性映射。

① 功率分区：以你的 FTP 为基准，把当前功率换算成强度百分比（%FTP），落入恢复/耐力/节奏/阈值/无氧等区间。

② 分区映射心率：每个功率区间对应一段 %阈值心率，再乘以你的阈值心率得到目标心率。功率越高，目标心率越高。

③ 一阶平滑：心率不会瞬间跳变，按时间常数逐步逼近目标（上升快、下降慢，贴近真实生理）。

算法逻辑说明

心率动力学：HR(t) = HR + α·(目标 − HR)，α = 1 − e^(−dt/τ)。上升 τ≈30s，下降 τ≈60s，还原心率惯性。

心率变异 HRV：叠加呼吸性窦性心律不齐（RSA）、Mayer 波与缓慢漂移，让静息心率也有自然抖动。

浮动平滑游走：固定模式下功率/踏频/心率在 [基准±浮动] 带内做有界随机游走——周期性在带内取新目标再平滑逼近，因此平稳变化、绝不越界、不逐拍乱跳。

参数持久化：所有设置写入 NVS，断电重启后自动恢复。

使用说明

1. 连接骑行 App：在 Zwift、TrainerRoad 等 App 搜索并连接 BikePower BLE 设备。

2. 选择模式：首页顶部切换「固定模式 / 配速机器人」，二选一。

3. 调整参数：输入基准值并用 ± 微调浮动范围，点击保存生效。

4. 配网窗口：默认 180 秒，剩余不足时点「续期配网」。

5. 重新配网：长按设备按钮 2 秒重新进入配网模式。

注意事项

· 保存生效：修改后需点「保存配置」才会持久化。

· 关闭 WiFi：点「保存并关闭 WiFi」返回骑行模式，BLE 持续在线。

· 固件升级：暂不支持 OTA，请通过烧录工具更新。
