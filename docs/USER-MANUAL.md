# BikePower C 用户手册

本手册面向普通骑行爱好者。
你不需要懂代码，只要按步骤操作，就能把设备接电、连接 App、调功率和修改设置。

BikePower C 是一台运行在 ESP32-C3 上的蓝牙骑行功率计模拟器。
它会向骑行 App 广播功率、踏频、心率等数据；需要改设置时，再临时切到 WiFi 配网页面。

默认蓝牙名称为 `BikePower`。
默认 WiFi 热点名称也为 `BikePower`。
当前固件版本为 `v3.0.0`。

## 第一章：产品介绍

BikePower C 适合智能骑行台、训练 App、DIY 骑行附件和室内训练场景。
你可以把它理解成一块“小型训练控制盒”：开机先通过蓝牙工作，设置参数时再进入网页配网。

相比脚本方案，C 版更稳定、更适合长时间运行。
日常使用时，你主要接触三个东西：按钮、LED 指示灯、骑行 App。

## 第二章：开箱清单

开始前，请准备：

- 一块 ESP32-C3 开发板
- 一根可正常供电和传输数据的 USB 线
- 一个稳定电源

如果只是体验功能，这三样就够了。

## 第三章：快速安装

当前固件默认接线如下：

- 按钮接 `GPIO9`
- LED 接 `GPIO12`
- 通过 USB 或稳定 `5V` 为开发板供电

最简接线步骤：

1. 按钮一端接 `GPIO9`
2. 按钮另一端接 `GND`
3. LED 控制脚接 `GPIO12`
4. 通过 USB 给开发板供电

如果开发板自带按钮和 LED，可能不需要额外外接。
第一次上电后，先观察 LED 状态，再打开骑行 App 搜索蓝牙设备。

## 第四章：第一次使用

第一次使用建议按下面顺序操作：

1. 给设备上电
2. 等待设备启动
3. 打开手机、平板或电脑上的骑行 App
4. 进入搜索蓝牙设备页面
5. 搜索 `BikePower`
6. 点击连接或配对
7. 连接成功后开始训练

正常情况下：

- LED 慢闪：设备正在蓝牙广播
- LED 常亮：设备已经连接成功

## 第五章：按钮操作指南

设备主要靠一个按钮完成日常操作。

- 短按：功率减少 `20W`
- 长按约 `0.5s` 后继续按住：每 `200ms` 自动增加 `20W`
- 长按到 `2s` 以上再松开：进入配网确认窗口
- 确认窗口内再按一次：正式进入 WiFi 配网模式
- 确认窗口超时不再按：约 `3s` 后自动取消，回到蓝牙状态

更容易记住的方式：

- 想减功率：点一下
- 想手动加功率：按住但不要超过 2 秒
- 想改配置：按住超过 2 秒，松手后再补按一次

## 第六章：LED 灯效说明

常见灯效如下：

| LED 表现 | 当前状态 | 用户理解 |
|------|------|------|
| 慢闪 | BLE 广播中 | 已开机，正在等待 App 连接 |
| 常亮 | BLE 已连接 | 已连接成功，正在正常工作 |
| 快闪 | 等待二次确认 | 设备在等待你确认是否进入配网 |
| 慢闪 | WiFi 配网中 | 设备已切到热点模式，可连接热点改设置 |
| 熄灭 | 切换或重启中 | 稍等几秒，设备会恢复 |

## 第七章：WiFi 配网设置

BikePower C 不会开机自动进入 WiFi。
只有手动长按并二次确认后，设备才会切到配网模式。

完整流程如下：

1. 长按按钮至少 `2s`
2. 松开后看到 LED 快闪
3. 在快闪窗口内再按一次按钮
4. 设备关闭蓝牙，打开 WiFi 热点
5. 手机连接热点 `BikePower`
6. 输入密码 `12345678`
7. 打开浏览器访问 `192.168.4.1`
8. 修改需要的配置
9. 点击“保存并重启”
10. 设备自动重启并恢复蓝牙模式
11. 回到骑行 App 重新连接

如果手机提示“此网络无互联网”，这是正常现象，继续连接即可。

## 第八章：骑行模式说明

### 1. Steady 固定功率

你手动设置功率、踏频、心率，设备按这些值附近的小幅波动来广播。
适合测试、热身、固定强度骑行。

### 2. Road 配速机器人

设备会根据你的体重和所选配速机器人的 W/kg 区间换算功率。
适合模拟跟骑和稳定配速骑行。

### 3. ERG 智能训练

支持 FTMS/ERG 的训练 App 会主动下发目标功率。
适合结构化课程和间歇训练。

简单选择建议：

- 想手动控制：选 `Steady`
- 想模拟跟骑：选 `Road`
- 想跟训练课：选 `ERG`

## 第九章：Web 配网界面字段说明

进入 `192.168.4.1` 后，主要会看到首页和“更多配置”页。

首页字段：

- `power`：基础功率，范围 `0-2000W`，仅 `Steady` 模式有效
- `cadence`：基础踏频，范围 `20-120RPM`，仅 `Steady` 模式有效
- `heartrate`：目标心率，范围 `60-200BPM`，仅 `Steady` 模式有效
- `mode`：骑行模式，可选 `Steady`、`Road`、`ERG`

更多配置字段：

- `device_name`：蓝牙广播名称，建议简短易识别
- `profile_weight`：体重，范围 `40-150kg`
- `profile_ftp`：FTP 功率，范围 `50-500W`
- `profile_thr_hr`：阈值心率，范围 `100-220BPM`
- `profile_ride_type`：配速机器人类型

配速机器人选项：

- `Coco`：`2.4-2.8 W/kg`
- `Yumi`：`2.7-3.1 W/kg`
- `Jacques`：`3.0-3.5 W/kg`
- `Genie`：`3.5-3.9 W/kg`
- `Constance`：`4.0-4.4 W/kg`

正确保存流程是：

1. 在“更多配置”里修改个人信息或设备名
2. 点“应用并回首页”
3. 回首页后点“保存并重启”
4. 等待重启完成

## 第十章：常见问题与排障

### 1. 搜不到 BLE 设备怎么办？

先看 LED 是否慢闪。
如果没有灯效，先检查 USB 线、电源和开发板供电。
如果有灯效但搜不到，请重新打开 App 搜索 `BikePower`。

### 2. 为什么进入不了配网？

进入配网必须两步都做：
先长按至少 `2s`，再在确认窗口里补按一次。
只做第一步，设备会自动取消并回蓝牙模式。

### 3. 手机连上热点后打不开页面怎么办？

确认连的是 `BikePower` 热点。
直接在浏览器输入 `192.168.4.1`，不要依赖搜索引擎或外网跳转。

### 4. 配网失败或保存后没反应怎么办？

先确认是否真的点了“保存并重启”。
保存后设备会暂时断开，几秒后再重新搜索蓝牙设备即可。
如果反复失败，优先排查供电是否稳定。

### 5. 感觉功率不准怎么办？

先确认当前模式。
`Steady` 是手动设定值附近的小幅波动，`Road` 会按体重和机器人换算，`ERG` 会受 App 下发目标影响。
如果想固定在明确瓦数附近，请切回 `Steady`。

### 6. 重启后设置丢失怎么办？

常见原因是只“应用并回首页”但没有最终“保存并重启”，或者保存过程中断电。
正确流程是修改后点击“保存并重启”，并等待设备完整重启。

## 第十一章：技术规格

引脚定义：

- 按钮：`GPIO9`
- LED：`GPIO12`
- 供电：USB / `5V`
- 调试串口：`UART0`

范围与默认值：

- 功率范围：`0-2000W`
- 踏频范围：`20-120RPM`
- 心率范围：`60-200BPM`
- 默认功率：`260W`
- 默认踏频：`90RPM`
- 默认心率：`150BPM`

BLE 服务列表：

- `CPS`：功率数据
- `HRS`：心率数据
- `CSC`：踏频相关数据
- `FTMS`：训练机数据和 ERG 控制
- `DIS`：厂商、型号、固件版本信息

记住三件事就能顺利用起来：

1. 上电后先连蓝牙
2. 需要改配置时再进 WiFi
3. 保存后等设备重启，再回 App 重连
