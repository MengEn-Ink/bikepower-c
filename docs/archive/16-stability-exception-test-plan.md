## 用例与通过条件

| 场景 | 验证方式 | 必须满足 |
|---|---|---|
| 首次读取 HTTP 失败或非法 JSON | 浏览器拦截 state | 不显示成功，不可提交；恢复后刷新能读取 |
| 轮询断网、恢复 | 浏览器拦截 runtime | 实时值显示不可用，草稿保留；恢复后真实值更新 |
| 配置被另一客户端修改 | 第二个 HTTP 客户端保存 | revision 更新，草稿保留，下一次保存可成功 |
| 请求未送达、保存失败、忙拒收 | HTTP 拦截与生产 callback | 配置不变，失败可见，按钮解锁，可重试 |
| 保存成功但响应丢失 | 请求转发后丢弃响应 | 查询确认实际结果，不发送重复自动保存，不假报成功 |
| 快速重复保存 | 延迟 POST 后连续点击 | 至多一笔在途事务，不丢字段 |
| 扫描失败、候选过期 | 传输拒绝与重新扫描 | 输出来源不变，可重新扫描与测试 |
| 临时测试取消、同地址不同类型 | 浏览器与已有扫描 harness | 未启用不改变实际输出，候选身份隔离 |
| 桥接 0W、过期、断线、恢复 | 浏览器、生产会话和设备夹具 | 归零不泄漏旧值，状态明确，恢复可继续 |
| 关闭 WiFi 保存失败、确认关闭 | 浏览器与生产 callback | 失败保持门户可操作，成功才进入关闭态 |
| BEGIN 拒绝、组写失败、COMMIT 失败 | 实际 Pages 事务 + BLE 替身 | current/revision 不假更新，组失败尽力 CANCEL |
| 响应损坏、串事务、提交后断连 | 实际 Pages response matcher | 忽略异事务，超时/断连显式提示核实，监听器释放，无未处理 Promise 拒绝 |
| HTTP 空/超长/截断/分段/超时/非对象 | 生产 receive/submit handler | 拒绝非法输入；合法分段可恢复；无配置副作用 |
| 小数 revision、未知事务结果 | 生产 submit/result handler | 拒绝非整数 revision；不将未知结果作为本次成功 |
| 回调拒收、NVS 失败、revision 冲突 | 生产事务链路 | pending 清理，配置及 revision 不误更新，重试可完成 |
| BLE 重启、运动切换、原配置恢复 | 既有设备自动门禁 | 每 opcode 真实样本验证，二次独立扫描重连，结束回读原配置 |
