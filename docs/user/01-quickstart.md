# BikePower 快速上手

[先看操作动画](https://mengen-ink.github.io/bikepower-c/#operations) · [离线动画手册](pages-mobile-guide.html)

已预装的设备，直接从连接 App 开始。

| 做什么 | 跟着演示 |
|---|---|
| 首次安装 | 电脑 Chrome / Edge 打开[工具站](https://mengen-ink.github.io/bikepower-c/)，接好数据线，选择对应设备，按弹窗完成安装 |
| 连接 App | 给设备接电，App 添加功率计 / 心率计 / 踏频传感器，选择 BikePower |
| 打开配置 | 操作键按住至少 2 秒，松开，3 秒内再按一次 |
| 手机连接 | 热点 BPW_XXXX，密码 12345678；没弹出配置页就打开 http://192.168.4.1 |
| 保存退出 | 修改后等待“保存成功”，再关闭 WiFi，回到 App |

**注意**

- 安装要用数据线；写入时别拔线，完成以安装弹窗为准。擦除会清掉配置。
- 热点提示“无互联网”正常，选择保持连接。
- App 配对前先释放网页连接，设备一次只连接一端。
- 关闭页面不会保存草稿；页面更新不会自动升级设备。

更多操作看[动画手册](pages-mobile-guide.html)，供电与接线看[硬件指南](03-hardware.md)。
