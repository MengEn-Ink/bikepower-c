# OTA 固件升级操作手册

> 适用固件：v3.1.6 及以上
> 适用读者：测试人员、最终用户、技术支持
> 更新日期：2026-06-28

---

## 一、功能概述

BikePower C 支持通过家庭 WiFi 在线检查并下载最新固件（OTA），无需 USB 数据线连接电脑，也无需手动上传固件文件。设备会自动连接家庭网络，从服务器查询最新版本，确认有更新后下载写入并重启。升级流程内置防降级保护和自检回滚机制，确保升级失败时设备不会变砖。

### 核心特性

| 特性 | 说明 |
|------|------|
| 在线升级 | 设备连家庭 WiFi 从服务器下载最新固件，无需手动上传 bin 文件 |
| 防降级 | 仅当远端版本高于当前版本时才提示更新，拒绝降级 |
| 自检回滚 | 新固件启动 10s 内若关键模块初始化失败，自动回滚到上一版本 |
| 流式写入 | 固件分块写入 Flash，不整包驻留内存 |
| 凭证统一 | 家庭 WiFi 凭证在「更多 → 家庭网络」统一配置，升级页只读展示 |

## 二、前置条件

| 项目 | 要求 |
|------|------|
| 设备版本 | v3.1.6 及以上（已含在线 OTA 功能） |
| 家庭 WiFi | 已在「更多 → 家庭网络」配置好可上网的家庭 WiFi |
| 手机/电脑 | 支持 WiFi 连接 + 浏览器 |
| 设备电量 | 已通电运行（USB 供电或电池） |
| 服务器 | OTA 版本服务器（`OTA_VERSION_URL`）可访问 |

> 若尚未配置家庭 WiFi，固件升级页面会提示「未配置」并引导跳转到「更多 → 家庭网络」。

## 三、升级操作步骤

### 步骤 1：进入配网模式

1. 确保设备已通电，LED 处于呼吸/常亮状态（BLE 活动态）。
2. **长按按钮 2 秒以上**，LED 切为快闪（进入二次确认窗口）。
3. **3 秒内再按一次按钮**，LED 熄灭，设备进入 WiFi 配网模式。
4. 设备启动 SoftAP，SSID 为 `BikePower`，密码 `12345678`。

> 超时提示：确认窗口 3 秒内未再按按钮则自动取消，回到 BLE 活动态。

### 步骤 2：连接设备 WiFi

1. 打开手机/电脑的 WiFi 设置。
2. 找到网络 `BikePower`，输入密码 `12345678` 连接。
3. 连接成功后，**手机通常会自动弹出配网页面**（Captive Portal）。
   - 若未自动弹出，手动打开浏览器访问 `http://192.168.4.1`。

### 步骤 3：（首次）配置家庭网络

若此前未配置过家庭 WiFi：

1. 进入配网页面，点击**「更多」**。
2. 点击**「家庭网络」**，扫描周边 WiFi，选择自家路由器并输入密码。
3. 保存后设备会测试连接，确认能联网成功。

> 家庭 WiFi 凭证保存在设备 NVS，后续升级无需重复配置。

### 步骤 4：检查更新

1. 回到配网页面，点击**「更多」→「固件升级」**进入 OTA 页面。
2. 页面顶部显示**当前版本**，下方只读展示**已配置的家庭网络名称**。
3. 点击**「检查更新」**。
4. 设备临时连接家庭 WiFi（不影响配网热点），从服务器拉取最新版本信息，约 10-30 秒。
5. 页面显示结果：
   - **发现新版本**：显示服务器最新版本号、更新说明，并启用「下载并升级」按钮。
   - **已是最新版本**：提示无需升级。

### 步骤 5：下载并升级

1. 确认有更新后，点击**「下载并升级」**，二次确认。
2. 设备收到指令后：
   - 关闭配网热点和蓝牙，独占 WiFi 资源。
   - 连接家庭 WiFi，从服务器下载完整固件，分块写入 Flash。
   - 写入完成并校验后自动重启进入新固件。
3. 页面显示「正在下载升级」提示，告知用户约 2 分钟后重启、保持通电。
4. 设备重启后，重新连接蓝牙即可继续使用。

> 全程预计 1-2 分钟（取决于固件大小和家庭网络速度）。期间请勿断电。

### 步骤 6：验证升级结果

1. 设备重启后，BLE 广播名称仍为 `BikePower`。
2. 用骑行 App 连接设备，确认数据正常推送。
3. （可选）再次进入配网 → 固件升级页，确认版本号已更新。

## 四、防降级规则

| 场景 | 设备行为 | 页面提示 |
|------|---------|---------|
| 远端版本 > 当前版本 | 提示有更新，允许下载升级 | 「发现新版本！」 |
| 远端版本 = 当前版本 | 不提示更新 | 「已是最新版本」 |
| 远端版本 < 当前版本 | 不提示更新（防降级） | 「已是最新版本」 |

版本号格式：`vMAJOR.MINOR.PATCH`（如 `3.1.6`），按 major.minor.patch 逐段数值比较；非该格式回退字符串比较。

> 在线模式下不支持「同版本重刷」：检查阶段同版本即视为无更新，不会出现升级按钮。如需重刷当前版本，请通过 USB 重新烧录。

## 五、自检与回滚机制

新固件首次启动时处于待确认状态（PENDING_VERIFY）：

```
新固件启动
  ├─ 关键模块（BLE 等）初始化成功 → 10s 自检窗口到期 → 确认有效（VALID）→ 正常运行
  └─ 关键模块初始化失败 → 立即标记无效 → 自动回滚到上一固件
```

- 自检窗口 10 秒，期间关键模块正常工作则到期自动确认。
- 若自检失败，设备自动回滚，下次启动回到上一版本。
- 用户无需干预，回滚后设备可正常使用旧版本。

## 六、常见问题排查

### Q1：手机连上 BikePower WiFi 后没有自动弹出网页

**可能原因**：部分手机系统 Captive Portal 检测被关闭或延迟。

**解决方法**：
1. 手动打开浏览器，访问 `http://192.168.4.1`。
2. Android 用户可尝试关闭再开启 WiFi 重触发检测。
3. iOS 用户可尝试在 WiFi 设置页点击设备名称旁的"i"。

### Q2：检查更新提示「请先在更多页面配置家庭网络」

**原因**：设备 NVS 中未保存家庭 WiFi 凭证。

**解决方法**：
1. 进入「更多 → 家庭网络」，扫描并配置可上网的家庭 WiFi。
2. 确认测试连接成功后，再回到固件升级页检查更新。

### Q3：检查更新失败 / 提示「WiFi连接失败」

**可能原因**：家庭 WiFi 密码变更、信号弱、或家庭路由器 2.4G/5G 混频导致连接异常。

**解决方法**：
1. 进入「更多 → 家庭网络」重新输入密码并测试连接。
2. 靠近路由器重试。
3. 确认家庭 WiFi 为 2.4G 频段（ESP32-C3 不支持 5G）。

### Q4：检查更新失败 / 提示「无法获取版本信息」

**可能原因**：设备已连上家庭 WiFi，但无法访问 OTA 版本服务器（`OTA_VERSION_URL`）。

**解决方法**：
1. 确认家庭网络可正常访问外网。
2. 确认 OTA 服务器地址配置正确、服务正常。
3. 稍后重试。

### Q5：升级后设备无法启动 / LED 异常

**可能原因**：新固件自检失败已自动回滚，或下载过程中固件损坏。

**解决方法**：
1. 等待 15 秒，设备可能正在回滚并重启。
2. 若仍无响应，拔插 USB 重新通电。
3. 设备应自动回到上一可用版本。若仍不行，联系开发者通过 USB 重新烧录。

### Q6：配网模式超时自动退出

**原因**：配网模式有超时保护，超时后自动关闭 WiFi 回到 BLE。

**解决方法**：重新长按按钮进入配网模式即可。

### Q7：升级过程中断电会怎样

**影响**：Flash 写入中断，新固件不完整。

**设备行为**：
- 重新上电后，bootloader 检测到新固件未确认（PENDING_VERIFY），自动回滚到上一版本。
- 设备可正常启动旧版本，不会变砖。

## 七、技术规格

| 项目 | 规格 |
|------|------|
| 固件分区 | ota_0 / ota_1 双分区互切，各 1.75MB |
| 升级方式 | HTTPS 在线下载，分块流式写入 |
| 版本校验 | 远端 `version` 与运行时 `FIRMWARE_VERSION` 语义比较，仅 > 才升级 |
| 回滚机制 | ESP_OTA_IMG_PENDING_VERIFY + 10s 自检窗口 |
| 凭证存储 | 家庭 WiFi SSID/PSK 保存在 NVS，OTA 页只读展示 |
| Flash 布局 | 4MB（nvs + phy + ota_0 + ota_1 + otadata + coredump） |
