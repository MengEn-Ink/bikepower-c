01四步上手

  1. 烧录固件 电脑

    用能传数据的 USB 线连接开发板，在电脑上打开本页 →「固件刷写」→ 选择板型 → 连接串口并刷写。

  2. 连接骑行 App 手机 / 平板

    上电后 LED 慢闪即开始广播。在骑行 App 里按功率计、心率计、踏频传感器或智能训练台搜索 BikePower。

  3. 日常操作 设备

    用操作键调整目标值；按压时长和反馈见下方按键操作示范。

  4. 修改配置 手机即可

    需要调整模式或接入真实功率计时，按手机配网步骤进入配置页。

03用手机修改设备配置

Pages 是手册与电脑工具台。设备配置页在开发板自己的热点里，需要先连接热点。

版本说明：网页烧录提供正式 Release。下文新版门户与三设备主备桥接对应当前源码候选，仍待实物验收；页面更新不代表这些功能已经发布。请先核对设备固件版本。
  1. 进入配网：操作键长按至少 2 秒，松开；看到确认快闪后，在 3 秒内再按一次。
  2. 连接热点：手机 WiFi 设置选择 BikePower-XXXXXX，密码 12345678。“无互联网”属于正常现象，请选择保持连接。
  3. 使用自动弹窗：连接热点后，手机会自动弹出配置窗口，直接按页面提示操作。若没有弹出，再打开 Safari 或 Chrome，手动输入 http://192.168.4.1；弹窗无法正常操作时，也可用完整浏览器打开。
  4. 选择运动和输出：切换骑行 / 跑步，填写必要参数。骑行可选模拟固定模式、配速机器人或真实来源；自定义档用于设置强度范围。
  5. 保存并核对：点击页面保存按钮，等待成功提示，再核对回显和 App 数据。失败时保留页面，检查输入后重试。
  6. 结束配网：默认开放 5 分钟。需要更多时间时主动续期，并以实际倒计时为准；先保存成功，再点击“关闭 WiFi”并确认，或等待超时关闭。
普通配网期间 BLE 继续工作。修改运动类型或广播服务，保存可能引起短暂断连，需要重新配对。热点关闭后，设备页暂时无法访问属于正常现象。

04接入真实功率计

真实功率计→盒子校正→骑行 App
  1. 唤醒功率计：转动曲柄让它广播；若被其他 App 占用，先断开。
  2. 选择真实来源：在设备配网页主动扫描，选择支持 CPS 的功率计；无名称设备也可使用。点击测试，等待两份合法功率样本确认来源。
  3. 设置校正：固定偏移：200 W + 10 W = 210 W；比例：200 W × 105% = 210 W。两种方式择一，也可不校正。
  4. 核对身份与心率：按需复制已读取的设备信息或自定义盒子名称。真实来源默认关闭心率广播；手动开启后，心率仍来自模拟。
  5. 保存主备：最多保存三台设备，可设首选、删除或替换。校正由三台共享；测试成功不等于正式切换，保存后核对原始值、校正值和连接状态，再让骑行 App 连接盒子的广播名称。
停踩与断线保护：真实输入 0 W 时保持 0 W，固定偏移和比例均不作用于 0 W；旧样本超过 3 秒会清除。重启或断开后，按最近成功设备优先定向恢复，60 秒内最多两轮；失败后改为完整模拟输出，并每 60 秒轮转探测一台已保存设备。持久配置仍保留真实来源。仅桥接功率和同源踏频，恢复及 WiFi 共存需要实物确认。

05切换跑步模式

设备配网页选择跑步，设置速度或配速模板、步频与心率，保存后重新搜索设备。跑步和骑行使用不同服务，旧配对可能需要重新建立。

  1. 固定与配速：固定模式设速度；配速模式选模板或自定义范围。配速数值越小，速度越快。
  2. 开始与暂停：支持的 App 可通过 FTMS 开始 / 恢复或停止 / 暂停。暂停后速度、步频与步幅归零，距离和用时冻结。
  3. 重置：清空累计距离和用时，保持此前的运行 / 暂停状态。暂停后重置仍需恢复才继续累计。
App 对 RSC 与 FTMS 的支持不同。若只有心率被识别，先确认 App 是否支持跑步传感器，再核对运动类型和广播项。

连接兼容性诊断

骑鬥或码表搜不到、连不上、连接后无数据时，先确认支持 BLE、搜索角色与当前运动模式。开发板只允许一个下游连接，先关闭占用它的网页或 App。

  1. 电脑 Chrome / Edge 打开本站「设备比对」，填写目标、版本、系统和失败阶段，添加开发板与同一目标下正常的参考设备。
  2. 等待通知后冻结快照、分析服务与能力差异。读取失败和未授权会显示为未知；名称复制不会复制 GATT 或私有握手。
  3. 点击「释放连接并开始实测」，本站所有标签页暂停连接，刷新仍暂停。到目标端验证，再记录并导出诊断 JSON。
  4. 建议连续连接 5 次、稳定收数 30 分钟；关闭目标端连接后，结束实测并手动重新连接网页。

06拿起实物，逐项验收

在实物上操作后手动勾选。这里只记录本页自查，刷新后清除，不生成固件通过报告。

M5Stamp C3 默认：广播蓝色慢闪、连接绿色常亮、确认黄色快闪、配网青色慢闪。通用板仅用单色灯表示节奏。自定义灯效或静默时，以实际配置为准。

07遇到问题，从这里排查

找不到设备，或 App 连不上

重新上电唤醒广播，确认没有被另一个 App 或电脑工具台占用下游连接。关闭其他连接再扫描。改过运动类型、广播项或名称后，在 App 里删除旧配对再搜索。

连接热点后，没有自动弹出配置窗口

确认 WiFi 已连接 BikePower 热点，并选择保持无互联网连接。没有自动弹窗时，打开 Safari 或 Chrome 手动访问 http://192.168.4.1；仍打不开再检查影响本地访问的 VPN 或代理。热点超时关闭后，需要重新长按并确认。

长按了，为什么没有 WiFi

满 2 秒先松开，等待确认提示，再在 3 秒内按一次。一直按住无法二次确认。不要把 RST 当成操作键；静默灯效时结合计时与热点判断。

真实功率为 0，或扫描不到功率计

转动曲柄唤醒，确认支持标准 Cycling Power Service。解除其他 App 占用，重新扫描并测试。核对上游连接与样本状态；无新样本时的 0 W 是保护输出，不能证明功率计正常。

怎么升级，会不会清掉配置

电脑 Chrome / Edge 配合数据 USB 线，选择正确板型并核对版本。擦除会丢失配置，按弹窗提示决定并先备份。这里刷写正式 Release 固件，页面更新不代表新固件已发布。

演示能播放，就算验收通过吗

不能。动画只解释默认操作。按钮、灯色、手机 Safari、训练 App 兼容性，以及真实功率计与 WiFi 共存都需要实物验证，请逐项确认上方清单。
