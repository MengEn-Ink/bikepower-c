# BikePower C 使用手册

适用当前工作区 v4.2.1 核心门户与桥接功能；该批改动尚未发布。普通用户按已发布 Release 选择固件。

## 烧录与首次连接

用桌面 Chrome 或 Edge 打开 [项目工具站](https://mengen-ink.github.io/bikepower-c/)，选择对应板型，使用能传输数据的 USB 线连接开发板，再选择串口开始烧录。手机端不支持烧录。备用入口：[在线烧录](https://easyhey.com/?firmware=MOD220)。

固件文件名采用 `generic-c3-v4.2.1.bin` 或 `m5stamp-c3-v4.2.1.bin`；总包为 `bikepower-c-v4.2.1.zip`。Git ID 和构建时间在清单和设备详情中单独显示。

Pages 的 NVS 配置页支持切换骑行输出来源，以及原值、瓦数偏移（±200W）、比例（50.0–150.0%）校正。首次扫描、测试和绑定功率计需在设备配网页完成；Pages 保留已有绑定。切到真实来源时默认关闭模拟心率，可手动开启。旧固件缺少桥接配置组时仍可编辑原五组。

上电后默认工作在 BLE 模式。在骑行 App 中搜索 BikePower，配对功率、踏频和可选心率。配置已保存为真实来源时，设备会连接已绑定功率计；普通模拟模式不启动上游连接或扫描。

## 按钮与配网

| 操作 | 行为 |
|---|---|
| 短按，小于 300ms | 按当前步进增加模拟基础功率 |
| 按住 300ms–2s | 按当前步进降低模拟基础功率 |
| 长按超过 2s 后松开 | 进入二次确认窗口 |
| 5s 内再短按确认 | 开启配网 |

连接 `BikePower-XXXXXX` 热点后，手机会自动弹出配置窗口，直接在窗口中操作。没有弹出时，再打开浏览器手动访问 `http://192.168.4.1/`。手机显示“无互联网”时继续保持连接。普通配网期间 BLE 继续工作。

配网默认 5 分钟。点击“续期”重新计时；浏览、保存、扫描和测试不会自动延长。热点关闭后需要再次用按钮进入配网。

## 模拟骑行

默认骑行输出来源为“模拟”。固定模式和配速机器人共用同一配置区域：

1. 固定模式设置基础功率、踏频及浮动范围。
2. 配速机器人选择档位，按体重和 W/kg 区间生成自然变化；自定义档在机器人选项内，填写名称及上下限。
3. 心率可关闭、随功率联动或锁定固定值；联动使用 FTP 和阈值心率。
4. 点击“保存”后才改变实际输出；编辑中的数值是草稿，顶部实时值显示当前设备输出。

模拟模式支持训练 App 下发 FTMS ERG 目标。ERG 属于训练会话状态，不覆盖已保存的基础功率。

## 真实功率计桥接

仅接入一个真实功率计的功率与同源曲柄踏频，不接入独立心率或独立踏频设备。

1. 选择真实功率计来源，再主动开始扫描。仅显示支持 CPS 的设备；无名称设备使用地址区分。
2. 选择设备开始临时测试。测试期间保持原输出，连续收到两份有效通知后展开桥接配置。
3. 选择原值、固定瓦数偏移（±200W）或比例校正（50.0–150.0%）。页面同时预览原始值与校正值。
4. 首次测试默认关闭模拟心率，需要时自行打开。
5. 点击“保存”才切换实际来源。已绑定设备可通过重新连接按钮重试；更换设备需要重新测试。

停踩为 0W 时，正偏移也不会制造功率。数据超过 3 秒未更新或上游断开时输出归零；60 秒内尝试自动重连。上游没有曲柄字段时不补模拟踏频。桥接期间拒绝 ERG 目标。

## 复制设备信息

勾选“复制功率计设备信息”后，可查看厂商、型号、序列号和硬件、固件、软件版本。只复制成功读取且非空的字段，缺失字段保留原开发板信息。

名称可选择功率计名称、原开发板名称或自定义名称。开发板名称最多 23 UTF-8 字节，中文通常每字 3 字节。修改后保存；部分 App 需要重新扫描才能显示新名称。

## 跑步

切换“跑步”，选择固定配速或配速机器人。自定义在机器人档位内，设置快慢配速范围、步频及浮动。心率可随强度联动、固定或关闭。

保存运动 Profile 会重建 BLE 服务并短暂断开。兼容 App 可控制开始、暂停和重置；暂停时速度、步频归零，距离与用时冻结；重置清零累计并保持原运行或暂停状态。

## 参数与设备设置

| 参数 | 范围 |
|---|---|
| 基础功率 | 0–2000W |
| 骑行踏频 | 20–120rpm |
| 固定心率 | 60–200bpm |
| 体重 | 40–150kg |
| FTP | 50–500W |
| 阈值心率 | 100–220bpm |
| 按钮调功步进 | 5–50W |
| 跑步速度 | 3–25km/h |
| 跑步步频 | 120–220steps/min |

设备门户提供必要参数、设备名和固件详情。模板库与 LED 灯效设置迁移到电脑端工具；通过 Web Bluetooth 连接开发板后，在 NVS 配置面板修改灯效和静默模式。

## 保存和退出

点击“保存”后等待设备确认成功。失败时原配置继续运行，页面保留草稿；其他客户端更新配置时需重新读取。

点击“保存并关闭 WiFi”，确认后等待保存完成及约 5 秒收尾。热点关闭，BLE 继续工作。未保存草稿不会因关闭浏览器而自动保存。

## 常见问题

- 搜不到设备：确认供电、当前 Profile 和广播项；关闭占用同一连接的其他 App 后重新扫描。
- 进不了门户：长按超过 2 秒，松开，再在 5 秒内短按确认；连接热点后手动访问 `192.168.4.1`。
- 桥接归零：查看原始通知新鲜度和上游连接状态，确认功率计已唤醒且没有被其他设备占用。
- 心率不显示：真实桥接首次默认关闭心率，需主动开启并保存。
- 保存后值没变：确认设备反馈保存成功；顶部实时输出不会跟随未保存草稿。
- 模板或 LED 入口不见：这些配置已迁移到电脑端工具，设备门户只保留核心功能。

真机覆盖范围及待人工验证项见随固件 `test-report.md`，真实功率计和手机 Safari 的兼容性以实测为准。
