# BikePower C 使用手册

## 设备状态监控（源码候选）

打开[设备状态](https://mengen-ink.github.io/bikepower-c/#/device-status)，通过支持 Web Bluetooth 的 Chrome/Edge 连接含遥测服务的开发板。页面常驻显示空闲堆和 CPU 百分比，点击指标打开独立详情窗口；页面和窗口可分别暂停。RSSI 保留 dBm，缺失值显示“—”。手机可以打开状态页；Safari 不支持这里的 BLE 连接。

网页与骑行 App 共用开发板唯一的外设连接槽，测试 App 前点击“释放网页连接”。旧固件不含遥测时会显示升级提示；正式网页刷写目录仍只提供正式 Release，本轮遥测固件待实物验证，Pages 上线不代表已升级设备。

适用当前工作区 v4.2.1 核心门户与桥接功能；该批改动尚未发布。普通用户按已发布 Release 选择固件。

## 烧录与首次连接

用桌面 Chrome 或 Edge 打开 [项目工具站](https://mengen-ink.github.io/bikepower-c/)，选择对应板型，使用能传输数据的 USB 线连接开发板，再选择串口开始烧录。手机端不支持烧录。备用入口：[在线烧录](https://easyhey.com/?firmware=MOD220)。

固件文件名采用 `generic-c3-v4.2.1.bin` 或 `m5stamp-c3-v4.2.1.bin`；总包为 `bikepower-c-v4.2.1.zip`。Git ID 和构建时间在清单和设备详情中单独显示。

Pages 的 NVS 配置页支持切换骑行输出来源，以及原值、瓦数偏移（±200W）、比例（50.0–150.0%）校正。首次扫描、测试和绑定功率计需在设备配网页完成；Pages 保留已有绑定。切到真实来源时默认关闭模拟心率，可手动开启。旧固件缺少桥接配置组时仍可编辑原五组。

上电后默认工作在 BLE 模式。在骑行 App 中搜索 BikePower，配对功率、踏频和可选心率。配置已保存为真实来源时，设备优先定向连接最近成功的已保存功率计，再尝试其他备选；普通模拟模式不启动上游连接或扫描。

## 按钮与配网

| 操作 | 行为 |
|---|---|
| 短按，小于 500ms | 按当前步进降低模拟基础功率 |
| 按住 500ms–2s | 按当前步进连续增加模拟基础功率 |
| 长按超过 2s 后松开 | 进入二次确认窗口 |
| 3s 内再短按确认 | 开启配网 |

连接 `BikePower-XXXXXX` 热点后，手机会自动弹出配置窗口，直接在窗口中操作。没有弹出时，再打开浏览器手动访问 `http://192.168.4.1/`。手机显示“无互联网”时继续保持连接。普通配网期间 BLE 继续工作。

配网默认 5 分钟。点击“续期”重新计时；浏览、保存、扫描和测试不会自动延长。热点关闭后需要再次用按钮进入配网。

## 模拟骑行

默认骑行输出来源为“模拟”。固定模式和配速机器人共用同一配置区域：

1. 固定模式设置基础功率、踏频及浮动范围。
2. 配速机器人选择档位，按体重和 W/kg 区间生成自然变化；自定义档在机器人选项内，填写名称及上下限。
3. 心率可关闭、随功率联动或锁定固定值；联动使用 FTP 和阈值心率。
4. 点击“保存”后才改变实际输出；编辑中的数值是草稿，顶部实时值显示当前设备输出。

模拟模式支持训练 App 下发 FTMS ERG 目标。ERG 属于训练会话状态，不覆盖已保存的基础功率。

## 真实功率计桥接

最多保存三台功率计作为主备，同一时间只接入一台的功率与同源曲柄踏频，不接入独立心率或独立踏频设备。以下主备功能适用于当前未发布候选。

1. 选择真实功率计来源，再主动开始扫描。仅显示支持 CPS 的设备；无名称设备使用地址区分。
2. 选择未保存的设备开始临时测试。扫描和测试期间暂时释放原上游，使用模拟输出；连续收到两份有效通知后加入设备草稿，两份合法 0W 通知也可通过测试。
3. 选择原值、固定瓦数偏移（±200W）或比例校正（50.0–150.0%）。页面同时预览原始值与校正值。
4. 首次测试默认关闭模拟心率，需要时自行打开。
5. 点击“保存”才应用来源与设备列表。可将已保存设备设为首选或删除；列表已满时，测试新设备后明确选择要替换的槽位，再保存。
6. 查看“配置来源”和“实际来源”，使用“立即重试”重新开始快速恢复。三台设备共用同一组校正参数；自动恢复优先最近成功设备，无有效最近提示时按列表首选开始。

真实输入为 0W 时，固定偏移和比例均保持 0W。真实数据超过 3 秒未更新时归零；断开后在 60 秒内最多尝试两轮已保存设备，全部失败或窗口到期后切换完整模拟输出。降级期间每 60 秒轮转定向探测一台设备，恢复后自动切回真实数据，持久化来源仍保留为真实功率计。

真实来源无曲柄字段时不补模拟踏频；模拟降级阶段使用已保存的模拟功率、踏频和心率设置。配置为真实桥接时拒绝 ERG 目标。主备接管、重启恢复、真实 0W 与 WiFi/BLE 共存仍需按当前候选完成实物验收。

## 复制设备信息

勾选“复制功率计设备信息”后，可查看厂商、型号、序列号和硬件、固件、软件版本。只复制成功读取且非空的字段，缺失字段保留原开发板信息。

名称可选择功率计名称、原开发板名称或自定义名称。开发板名称最多 23 UTF-8 字节，中文通常每字 3 字节。修改后保存；部分 App 需要重新扫描才能显示新名称。

## 跑步

切换“跑步”，选择固定配速或配速机器人。自定义在机器人档位内，设置快慢配速范围、步频及浮动。心率可随强度联动、固定或关闭。

保存运动 Profile 会重建 BLE 服务并短暂断开。兼容 App 可控制开始、暂停和重置；暂停时速度、步频归零，距离与用时冻结；重置清零累计并保持原运行或暂停状态。

## 参数与设备设置

| 参数 | 范围 |
|---|---|
| 基础功率 | 0–2000W |
| 骑行踏频 | 20–120rpm |
| 固定心率 | 60–200bpm |
| 体重 | 40–150kg |
| FTP | 50–500W |
| 阈值心率 | 100–220bpm |
| 按钮调功步进 | 5–50W |
| 跑步速度 | 3–25km/h |
| 跑步步频 | 120–220steps/min |

设备门户提供必要参数、设备名和固件详情。模板库与 LED 灯效设置迁移到电脑端工具；通过 Web Bluetooth 连接开发板后，在 NVS 配置面板修改灯效和静默模式。

## 保存和退出

点击“保存”后等待设备确认成功。失败时原配置继续运行，页面保留草稿；其他客户端更新配置时需重新读取。

先点击“保存并应用”（切换运动或启用桥接时按钮文案相应变化），等待成功回显。再点击“关闭 WiFi”并确认；该操作关闭热点，不提交未保存草稿。热点关闭后 BLE 继续工作，关闭浏览器也不会自动保存草稿。

## 常见问题

- 搜不到设备：确认供电、当前 Profile 和广播项；关闭占用同一连接的其他 App 后重新扫描。
- 进不了门户：长按超过 2 秒，松开，再在 3 秒内短按确认；连接热点后手动访问 `192.168.4.1`。
- 桥接归零或显示模拟降级：查看实际来源、恢复倒计时和上游连接状态，确认已保存功率计已唤醒且没有被其他设备占用；必要时点击“立即重试”。
- 心率不显示：真实桥接首次默认关闭心率，需主动开启并保存。
- 保存后值没变：确认设备反馈保存成功；顶部实时输出不会跟随未保存草稿。
- 模板或 LED 入口不见：这些配置已迁移到电脑端工具，设备门户只保留核心功能。

### 软件或码表连接兼容性诊断

在电脑 Chrome / Edge 打开在线工具台的“设备比对”，填写任意 BLE 软件或码表的名称、版本、系统、设备角色和失败阶段。添加开发板与在同一目标正常的参考设备，确认参考条件，等待通知后冻结两台快照并分析。报告区分标准问题、候选原因与未知项；已知私有服务可填 UUID 后重新授权，读取失败不等于缺失。

点击“释放连接并开始实测”后，本站所有标签页暂停连接，刷新后仍暂停；其他网站和 App 需自行断开。在目标端验证发现、连接、数据、重连和可选控制，建议连续连接 5 次及稳定收数 30 分钟。保存人工结果并导出 JSON；修改场景或重新冻结快照会清除旧结果。关闭目标端连接后，结束实测并手动连接网页。

浏览器不能获取完整广播、硬件 MAC 或目标软件握手。身份模板仅复制名称与 DIS 字段，不能复制服务结构或私有协议；具体兼容结论以目标版本实测为准。

真机覆盖范围及待人工验证项见随固件 `test-report.md`，真实功率计和手机 Safari 的兼容性以实测为准。
