# BikePower 使用说明

**先看动画，再动手。** [在线演示](https://mengen-ink.github.io/bikepower-c/#operations) · [离线动画手册](pages-mobile-guide.html)

动画涵盖安装、连接 App、按钮、手机热点、保存、功率校正、跑步和故障排查，可播放、暂停或逐步查看。

这份说明对应 v4.4.1 功能；实际以设备已安装版本为准。

| 操作 | 一句话说明 |
|---|---|
| 首次安装 | 电脑 Chrome / Edge + 数据线，按安装弹窗选择设备并确认；预装设备跳过 |
| 连接 App | 骑行优先按功率计搜索 BikePower；踏频随功率连接获取 |
| 按钮调节 | 短按减一步；按住 0.5–2 秒增加；默认步进 20 W，可设 5–50 W |
| 开热点 | 按住至少 2 秒 → 松开 → 3 秒内再按一次；不确认就取消，临时调节恢复原值 |
| 手机配置 | 连接 BikePower-XXXXXX，密码 12345678；自动弹窗或打开 http://192.168.4.1 |
| 设置骑行 | 默认固定模拟，直接填写功率、踏频与右侧 ±浮动，心率默认随动；需要机器人或真实功率计时展开“模式与来源” |
| 接真实功率计 | 转动曲柄唤醒 → 扫描 → 选择并测试 → 校正 → 保存 → 核对 App |
| 设置跑步 | 选择跑步，填配速和步频，用数字或滑杆调浮动，保存后释放旧连接并重新连接；App 需支持跑步传感器 |
| 修改名称 | 设备设置中修改、保存，然后在 App 重新搜索 |
| 修改指示灯 | 电脑连接设备，在配置面板设置灯效或静默，保存后核对 |
| 保存退出 | 等到保存成功，再关闭 WiFi；连续无操作 5 分钟自动结束，操作页面会续期 |

**特别注意**

- 配网要先松开再确认，别按复位键；灯色和节奏以你的设置为准。
- 热点“无互联网”正常；关闭热点后配置页无法访问也正常。
- 保存失败时保留页面重试；关闭热点或浏览器不会提交草稿。
- 初次配置先关注功率、踏频和模拟心率：新设备默认骑行、模拟输出、固定功率，心率随功率平滑变化。个人参数不确定时可保留默认。心率模式、来源与机器人、广播兼容、设备详情按需展开；展开不会提交配置，收起不会丢弃草稿。设备已有跑步、机器人、功率计或固定心率配置时正常恢复，打开网页不会重置它们。
- 本地新版配置页支持顶栏月亮 / 太阳图标切换主题，图标表示点击后切换的主题：首次跟随系统，手动选择后记在当前浏览器，刷新保持。禁用浏览器存储时只在当前页生效；切换主题不保存设备设置、不延长热点时间。设备需安装包含新版页面的固件，已发布 v4.4.1 页面不会因文档更新自动变化。
- 固定功率与踏频各用一栏显示目标和右侧 `±浮动`，例如 `220 W | ±50 W`、`88 rpm | ±8 rpm`。两侧均可直接键入，下方滑杆只调整浮动量，也支持方向键和 Home/End。非法数字原样保留并就近提示，保存等待时暂停编辑；机器人模式收起浮动，切回保留原值。详见[配置设计](../dev/62-portal-progressive-configuration.md)。
- 骑行/跑步切换位于页面中间，来源与模式按钮等宽铺满。心率、跑步配速与步频采用和功率相同的组合输入栏，例如 `145 bpm | ±7 bpm`、`5:30 /km | ±15 秒/km`、`170 spm | ±5 spm`，下方滑杆占满整栏；配速分钟和秒仍可分别编辑。浮动范围为心率 0–20 bpm、配速 0–60 秒/km、步频 0–20 spm，均填写整数。功率联动收起固定心率浮动，配速档收起固定配速浮动，切回保留原值；两种跑步模式均可调步频浮动。保存等待及配网结束时暂停编辑，详见[组合输入设计](../dev/61-portal-alignment-float-sliders.md)。
- 保存栏出现具体输入错误时，点击“定位错误”可展开并聚焦对应字段，不改变已选运动或模式。点击“恢复已应用配置”可撤销整页草稿，恢复设备最近确认的值；临时功率计测试也会停止，取消失败时草稿保留。恢复不会保存配置。
- 新版配置页顶部固定显示体重、FTP 和阈值心率，滚动或切换骑行/跑步仍可修改；关闭模拟心率也不会隐藏。体重填写 40–150 kg，FTP 填写 50–500 W，阈值心率填写 100–220 bpm，均为整数。修改属于草稿，等保存成功才应用；保存等待或配网结束时暂停编辑。
- 配速机器人骑行强度使用滑杆，也能直接点选档位或用键盘方向键；选“自定义”后填写 W/kg 范围。体重 × 强度决定模拟功率。70 kg 选 Coco（2.4–2.8 W/kg）为 168–196 W，FTP 300 W 时约 56–65%；改顶部体重或 FTP 后预览即时更新。范围条到 150% 为止，超过仍显示完整数字。比例仅作相对参考，不调节骑行台阻力，也不是通用难度等级。机器人浮动由引擎控制，固定模式的浮动字段在此模式下收起。预览属于草稿，等保存确认后才应用。
- 新配网页将点击、输入、选择、触摸和滚动阅读视为操作，成功续期后重新计时 5 分钟；鼠标移动、后台轮询和单纯切回页面不续期。最后 30 秒显示关闭提醒，可点“继续配置”；有未保存修改仍照常闲置关闭，不自动保存。结束页区分设备已确认结束与断网时状态待确认。此行为需安装 v4.4.1 固件。
- v4.4.1 支持两台下游 App 或网页同时接收数据及一台上游 CPS 功率计；模拟训练控制仍只有一个控制者。修改运动类型、服务开关或来源前，应断开另一台下游；通过WiFi修改这些项目需先断开全部下游。旧固件仍按原连接容量运行，网页更新不会自动增加设备连接数。
- 新配置默认开启“踏频随功率”：功率连接同时提供踏频，不再单独暴露 CSC。需要独立踏频传感器时可关闭此选项；升级不会覆盖已有设置；旧版本不会因文档或网页更新自动改变。
- 真实输入 0 W 时保持 0 W。断线可能回退模拟，请查看“实际来源”。最多保存三台功率计，共享校正；测试成功后仍须保存。
- 真实来源的心率默认关闭，开启后仍是模拟值；桥接功率与同源踏频。
- 跑步暂停后速度和步频归零，距离与用时冻结；恢复后继续。重置清空累计，保持原运行或暂停状态。
- App 控制训练强度时，手动骑行目标可能暂不生效。
- 首次训练控制时使用系统蓝牙配对并保存绑定，后续连接复用密钥；普通传感器读取不必主动配对。最多保存四个客户端，容量满不会自动删除旧绑定。
- 不要在没有证据时只在手机或电脑系统中“忘记设备”：板端可能仍保留旧绑定，此时重新配对需要维护人员核对。**例外：刚全量刷机/恢复出厂，或错误明确提示配对信息丢失时**，板端可能已无旧密钥，可仅移除电脑侧 BikePower：Mac“系统设置 → 蓝牙 → BikePower 详情 → 忽略此设备”；Windows“设置 → 蓝牙和设备 → 设备 → BikePower → 删除设备”。随后回 Pages 点击“扫描并连接设备”并确认。不清空全部配对，不整片擦除或改 MAC。
- 当前全量合并 BIN 从 0x0 写入会覆盖 NVS（配置与绑定），不勾整片擦除也不能保留。更新前导出配置；保留配置升级需要专门的升级流程，不能套用首次安装单文件。Pages 已提供按阶段的[蓝牙异常指引](../dev/66-pages-connection-recovery.md)。
- 刷写页选中版本后，按钮上方直接显示该版的新增功能、修复问题、其他改进与升级注意，支持最新及历史版本。同期网页工具变更单独折叠，网页不会随固件降级。完整 Release 原文与标签 CHANGELOG 可继续核对；未分类的版本明确提示摘要待整理，不套用其他版内容。
- 安装中别拔线；擦除会清掉配置。页面更新不会升级设备，功能以安装版本为准。

| 遇到问题 | 先这样试 |
|---|---|
| 搜不到 / 连不上 | 检查供电，释放其他连接，按正确传感器类型重新搜索 |
| 没有配置弹窗 | 保持热点连接，浏览器输入 192.168.4.1 |
| 长按后没有热点 | 松开，再在 3 秒内按一次 |
| 真实功率没有数据 | 唤醒功率计，关闭其他占用，核对实际来源，再测试 |
| 保存后没变化 | 查看成功提示；改过名称或运动类型，释放旧连接再重新搜索、连接 |

还没解决？电脑[工具站](https://mengen-ink.github.io/bikepower-c/)可做设备比对、[查看设备状态](https://mengen-ink.github.io/bikepower-c/#/device-status)并导出报告。复制名称与设备信息不保证 App 兼容；旧版本可能不支持新版功能。

动画是模拟教学。实际灯效、手机弹窗和 App 兼容性请在设备上确认；版本测试范围见随固件提供的测试报告。
