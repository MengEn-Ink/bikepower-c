# Pages 布局与移动手册验证报告

日期：2026-11-04。范围：Pages 页面与生成脚本，无设备写入、烧录或固件发布。

## 已完成

- 桌面导航按上手、设备、诊断组织，当前工具具有可读选中态和 `aria-current`。
- 设备配置按身份、桥接、骑行、跑步、个人资料、按钮灯效分区；运动类型切换渐进展开，不删除非当前运动参数。
- 手机手册包含八个章节、锚点目录、配网和桥接具体步骤、跑步语义、常见问题与实物自查。已删除重复工具介绍；配网流程明确自动弹窗优先，未弹出才手动访问。
- 按钮教学为四场景固定时间轴：短按、持续调功、长按二次确认、超时取消。展示按压、时长、目标功率与灯效状态，支持播放/暂停/重置/逐步。
- 页面不可见、演示离开视口时暂停；减少动画模式仅逐步显示，无持续闪烁。
- 页面更新信息由独立 `site-info.json` 提供构建时间和源码提交，明确北京时间和构建语义。正式固件版本来自 Release，错误时不保留伪造版本。
- 离线手册 `docs/user/pages-mobile-guide.html` 内联样式与教学脚本，不依赖网络资源；电脑打开也按阅读宽度显示。
