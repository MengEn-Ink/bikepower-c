# Pages 固件逐版本升级说明

## 范围与结论

刷写页在所选版本和刷写按钮之间，直接展示新增功能、修复问题、其他改进、升级注意与已知限制。覆盖目前可刷写的 v4.4.1、v4.4.0、v4.3.3、v4.3.0、v4.2.1、v4.2.0、v4.1.3；无明确单列修复的版本不编造修复项。

仅修改 Pages、生成索引、相关测试与用户说明。没有改 BIN、发行版本、MAC、NVS schema、刷写内核或写入范围；当前实体串口选中后的实物流程仍未验，不因本次页面回归而关闭该待办。

## 内容来源与边界

- `tools/web/firmware-release-notes.json` 为按正式标签绑定的分类摘要，包含每版来源链接；不是从当前 main 或“未发布”条目反推历史固件。
- v4.4.1、v4.4.0、v4.3.3、v4.1.3 依据正式 Release 正文。
- v4.3.0、v4.2.1、v4.2.0 的 Release 主要列附件，按相同正式标签的 `CHANGELOG.md` 补充功能摘要；页面可核对来源。
- 同期网页工具变更单独折叠，明确不随固件降级。近期 Pages 稳定性/异常话术没有冒充旧 BIN 内的新功能。
- 每个版本均提示升级和兼容限制。全量 `0x0` 镜像覆盖配置和绑定；v4.4.0 的独立 app-only 途径与网页实际全量按钮区分。
- 骑鬥心率角色限制、Service Changed/Windows缓存边界与未验设备矩阵保持，不承诺旧问题全部解决。

## 交互与降级

- 点击版本立即替换摘要、注意事项及原文；回滚确认仍须显式勾选，活动刷写会话禁止切换。
- 原 `notes` 900字符摘要为兼容保留；新增 `notes_full` 展示完整 Release，尾部升级内容不被截掉。
- `latest.json` 与 `releases.json` 均带同版 `changes`，历史索引缺失时单最新版回退仍保留说明。
- 新标签无已整理摘要时，显示“尚未整理分类摘要”，不使用其他版本内容；可查完整原文，保留全量升级风险提示。
- 采用既有主题/字体/布局令牌，桌面两栏、窄窗一栏，不扩大手机只读首页。
- 摘要与原文按纯文本处理；来源链接只允许本仓库 HTTPS GitHub，拒绝脚本与外域注入。
