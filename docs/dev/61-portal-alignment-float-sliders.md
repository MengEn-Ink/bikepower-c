# 61 - 配置页对齐与浮动滑杆统一

用户要求：“页面视觉对齐啊，模式切换居中对齐。还有其他的浮动设置也需要改为滑杆 一起都改下”。在已授权的本地页面上继续修正，不提交、部署、构建或烧录。

## 方案与范围

截图的两项切换只占整栏三分之二。根因是 `.source-segment/.two-options` 的两列规则先出现，后面的 `.segmented` 三列规则以同等优先级覆盖它。采用按实际按钮数量自动生成等宽列，文字保持居中；骑行/跑步顶层切换在页面中间。另一种修法是把所有两列规则放到三列规则后，但容易再次被顺序调整破坏，不采用。

浮动统一为已有精确数字输入加原生滑杆，保留功率/踏频组合栏；为固定心率、跑步配速、跑步步频补齐滑杆。全部复用草稿字段和原 API，不改参数范围或算法。以 JavaScript 生成三个滑杆和帮助说明，减少已经接近上限的 HTML；沿用共享同步、非法值保留、字段提示、保存/结束禁用。

| 控件 | 原字段 | 范围与单位 | 显示范围 |
|---|---|---|---|
| 心率浮动 | `hrFloat` / `hr_float` | 0–20 bpm，整数 | 固定心率；功率联动忽略此字段，收起并保留 |
| 配速浮动 | `runPaceFloat` / `run_pace_float_sec` | 0–60 秒/km，整数 | 固定配速；配速档由档位范围决定，收起并保留 |
| 步频浮动 | `runCadenceFloat` / `run_cadence_float` | 0–20 spm，整数 | 两种跑步模式均可调整 |

心率目标与浮动并列，步频与浮动并列，配速仍保留分/秒编辑与独立浮动说明；浮动滑杆放在对应数字下方。不引入滚轮、依赖库或额外设备缓冲区。
