# 57 - 顶部个人参数与骑行分档滑动设计

用户要求：FTP、阈值和体重放置在页面头部固定，方便修改；配速机器人骑行强度改为滑动选项，删除下拉框。本轮继续修改已批准的配置页，不另起视觉方向。

## 布局

采用同一顶部固定栏：第一行保留品牌、主题与会话，第二行并列体重、FTP、阈值心率。三项使用原字段 ID、草稿和配置事务，只保留一份输入；运动类型、功率来源和模拟心率开关不隐藏个人参数。手机保持三列、输入高度至少 44 px，桌面集中显示，避免铺满整个屏幕。

固定栏和浮动快捷按钮相比，直接显示数值且一步可编辑；和正文置顶相比，滚动后仍可修改。保留当前固定栏视觉，不新增弹窗。正文滚动留出顶栏高度；桌面输出摘要及闲置提醒避开顶栏。

## 强度选择

原生 `range` 按六档离散选择：Coco、Yumi、Jacques、Genie、Constance、自定义。档位名称读取设备数据。滑杆旁显示当前名称和 W/kg，下方为可横向滚动的直接点选按钮，支持点击、触摸、键盘方向键/Home/End；自定义仅表示自定范围，不代表最强档。

保留预计功率、相对 FTP 范围条和自定义上下限。滑动立即更新草稿预览，但不保存设备。固定模式与机器人切换保持原值。

## 生命周期与范围

读取未完成、保存等待或配网关闭时，顶部参数不可编辑；未知关闭状态核实后若恢复会话，恢复编辑。参数校验范围保持：体重整数 40–150 kg、FTP 整数 50–500 W、阈值心率整数 100–220 bpm。

仅修改生产 HTML/CSS/JS、浏览器门禁、手机演示及文档。算法、API、schema14、BLE、固件版本保持；不提交或部署。原资源预算保持，样式通过等价合并腾出空间。
