## 目标与已确认方案

用户已确认按 BikeControl 调研建议实施，并要求参考合宙 ESP32-C3 官方照片制作操作动画。保留现有 Pages 黑白灰主题、工具导航和真实连接链路，将教学放入手册首页与手机手册。

演示方案比较：

| 方案 | 适用范围 | 维护成本 |
|---|---|---|
| 分步图文与可点击动画（采用） | 按钮时序、保存回显、功率校正、连接交接 | 可按源码核对，支持暂停和键盘 |
| 实物录屏 | USB 选择器、手机热点和 App 特定页面 | 需对应版本的真实录像 |
| 单段循环动画 | 说明总体流程 | 难以练习、定位和阅读单一步骤 |

本轮采用第一种，并导出同源配网动画供查看与分享。实拍作为板型参考；教学画面不冒充实物验收或第三方 App 界面。

- 主操作区提前到首页；桌面工具折叠，阅读侧栏收起。其余 16 个章节变为可展开的短演示；按钮章节使用相同时间轴，其余 15 类使用模拟界面的点击、选中和结果反馈。

## 官方参考

- 原厂资料：<https://wiki.luatos.com/chips/esp32c3/board.html>
- 原厂正反面实拍与引脚图：[合宙官方参考图](../images/luatos-core-esp32c3-official-reference.png)。
- 参考板：经典 CORE-ESP32C3，21 × 51 mm，蓝色 PCB，顶部天线、两侧邮票孔、底部 Type-C。
- 正面朝向：RST 左、BOOT/GPIO9 右；D5/GPIO13 在 Type-C 左侧，D4/GPIO12 在右侧。
- 官方表将 D4/D5 定义为高电平有效。项目通用板当前默认低电平有效；本轮只标注位置和状态示意，不更改驱动或宣称灯效实测通过。

## 动画与交互

板图用可缩放的前视几何图绘制，按键、D4、天线与数据路径参与动画。使用实际默认阈值：短按小于 500 ms，持续调功每 200 ms 一步，满 2 秒松开回滚临时调功，3 秒确认窗口内再按才开启 WiFi。通用板 LED 保持单色，以闪烁节奏表达状态。

演示支持播放、暂停、下一步、重播和亲手按住 BOOT；切换场景、页面隐藏、离屏和减少动画偏好时停止连续播放。状态解释与图形同时更新，确认倒计时可阅读。所有示例值显式标为教学数据。

配套三个演示：

1. 配置草稿只在保存成功后影响示例输出；失败保留草稿并可重试。
2. 功率校正区分原值、固定偏移、比例增加，真实输入 0 W 时始终输出 0 W。
3. 网页连接与骑行 App 交接显示唯一连接归属。演示释放不会调用真实设备 API。

每个场景提供“操作位置、成功状态、失败排查、真实入口”。浏览器能力按实际 API 分开说明，手机使用热点配置不依赖 Web Bluetooth。
