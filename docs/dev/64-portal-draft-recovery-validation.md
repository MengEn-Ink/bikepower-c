# 64 - 配置草稿恢复验证报告

本轮按已批准的[计划](63-portal-draft-recovery-plan.md)实施隐藏错误定位、整页草稿恢复和资源收敛。固件版本保持 v4.4.0。

## 修复与证据

专项先确认恢复入口缺失而失败，再验证具体首错误、隐藏跑步/心率/浮动/名称/关联范围定位、聚焦无遮挡、保留运动和模式选择。恢复覆盖失败保存、设备外部 revision 更新、身份复制和临时功率计取消；取消返回 503 时保留草稿，保存等待和会话结束禁用。恢复不发配置保存请求。

统一校验和字段赋值，保留无设备时原 wire 名称，避免占位名称造成假草稿；取消前清理测试候选，防止迟到轮询恢复临时状态。原范围、API、NVS 和 BLE 不变。

基线 `10fd062` 的远端 CI 失败原因已修复：文档链接指向未入库本地截图报告；旧异常测试未展开来源区即点击隐藏按钮。文档改为仓库内说明或本地路径文字，测试补真实展开操作，原业务判据保持。
