## 问题与修复

受控 pair-only 测试不写配置、不改 GATT。旧无绑定候选首次加密成功，第二次建链后恢复加密返回 HCI 0x06（缺密钥）并由 Windows 拆链。提供程序裁剪了 Start Encryption 与配对参数，不能据此推断 EDIV/Rand 或密钥值。

改为标准 NimBLE 持久绑定，容量4、SC Just Works、ENC/ID分发；本机仍 public，FTMS WRITE_ENC 不降低，用户配置 namespace/schema 和分区不变。项目启动核验 NVS 记录格式与恢复内容，同身份更新补落盘回读，存储失败拒绝后续密钥恢复及训练控制。容量满拒绝新增，不自动删除旧客户端。host 同步时发送全范围 Service Changed，供服务表变更后重新发现。
