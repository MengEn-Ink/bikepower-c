# 63 - 配置草稿恢复与错误定位

用户已批准“资源收敛 → 错误定位 → 恢复已应用配置”，并要求测试后分批提交推送。本轮沿用现有界面与完整配置事务。

## 设计

采用现有表单内的错误定位和恢复入口，不添加库或自动保存。相比切换配置模式后跳转，临时展开错误字段可以保留用户已选运动、来源、机器人和心率模式；相比独立错误页面，原位置可直接修正，资源开销更小。

保存栏显示首个具体错误和“定位错误”按钮；所有阻止保存的字段都有对应位置。点击后打开祖先 details、临时展示隐藏祖先、聚焦并滚动到字段；不更改草稿模式、不发配置请求。修改后仍执行全量校验，下一个错误继续可定位。普通模式选择、恢复或成功保存重新按配置呈现。

编辑区提供“恢复已应用配置”。有草稿时可用，点击恢复最近从设备确认的配置，清除身份复制、自定义复制名称、临时选择与替换意图。取消正在进行的扫描/临时测试沿用既有停止和恢复上游流程，不更改持久设备列表。取消失败保留草稿与错误提示，成功后不发配置保存。保存忙态和会话结束时禁用入口。

资源收敛优先消除重复校验、草稿重置和文字赋值；原 HTML 21 KiB、CSS 24 KiB、JS 65 KiB 与总量 110 KiB 上限不变。不改 NVS、BLE、WiFi 生命周期或固件版本。
