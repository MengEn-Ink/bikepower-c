# 55 - 配置页强度反馈与交互细节

用户已批准按轻量动效建议优化配置页。本轮在当前工作台和双主题设计上落实细节。

## 方案与选择

| 方案 | 解释能力 | 资源与维护 |
|---|---|---|
| 五格难度等级 | 简单，但同档对不同体重和 FTP 的人含义不同 | 容易制造统一难度的错觉 |
| 功率区间与 FTP 范围条（采用） | 直接关联档位、体重、输出与个人参考 | 原生 HTML/CSS/JS，无额外依赖 |
| 动态仪表 | 视觉突出，但易混淆草稿与当前输出 | 占空间，增加动画与状态维护 |

档位名称读取设备返回的真实预设，补充 W/kg 区间。预计功率按固件整数公式 `体重 × 十倍 W/kg ÷ 10` 向下取整。70 kg 的 Coco 为 168–196 W；75 kg 的 Yumi 为 202–232 W。

FTP 比例使用上述功率除以当前填写的 FTP，仅作参考。范围条固定显示 0–150% FTP，100% 处有刻度；超出部分明确提示，真实数字不截断。不添加训练区间或统一难度等级。说明较高 W/kg 提高模拟功率，并不调节骑行台阻力。

## 交互细节

- 改档位、体重、自定义范围、FTP 时立即更新草稿预览；当前输出仍由已应用配置控制。
- 体重限定整数 40–150 kg，自定义范围限定 1–7 W/kg、一步 0.1；无效输入撤销对应预览，不显示 NaN 或旧比例，并阻止保存。
- FTP 无效时保留合法功率区间，撤销比例图示并指明 50–500 W 整数范围。
- 机器人模式收起固定模式的功率/踏频浮动字段，返回固定模式保留原值；机器人实际浮动由引擎控制。
- 保存期间明确显示等待设备确认，禁用重复提交；仅在现有设备事务确认成功后提示已应用，失败保留草稿。
- 范围条与按钮使用短 CSS 过渡，减少动画偏好下关闭，不引入持续动画。

## 影响与边界

修改生产 `main/web/` 三件套、专项浏览器门禁、派生手机演示及离线文档。算法、配置字段、NVS、API、BLE、版本号均保持。保持 HTML 21 KiB、CSS 24 KiB、JS 65 KiB、内联 110 KiB 原预算；先等价合并样式释放空间。

浏览器与 mock 验证不能替代设备验收。本轮不烧录；提交、部署与发布由后续明确授权启动。
