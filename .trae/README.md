# BikePower C — .trae/ 治理目录

AI 助手的工作知识库，分 7 个分类：

| 目录 | 用途 |
|------|------|
| `memory/` | 项目记忆（用户偏好、架构决策、踩坑经验） |
| `rules/` | 硬性规则（编码风格、硬件约束、WIFI/BLE、领域） |
| `rules/workflows/` | 工作流指导（上下文顺序、测试、迭代、任务模板） |
| `rules/domain/` | 领域知识（BLE 协议细节、WiFi 限制） |
| `skills/` | 可复用 Skill（每个子目录一个 SKILL.md） |
| `templates/` | 代码/文档模板 |
| `tasks/` | 任务跟踪（当前、待办、已完成） |

## 入口

`AGENTS.md` 是 AI 助手的主入口，任何编辑前必须先读它。
