弹窗由浏览器提供，网页不能替你自动选择，这是 Web Serial 的安全限制。macOS 选 “USB JTAG/serial debug unit”（底层 /dev/cu.usbmodem* 或 /dev/cu.usbserial-*，可能带 “- Paired / 已配对”），不要选 Bluetooth-Incoming-Port；Windows 选插拔后新出现的 “USB JTAG/serial debug unit (COMx)” 或 “USB 串行设备 / USB Serial Device (COMx)”，CP210x / CH340 板显示对应芯片名加 COM 口号。两种系统都要用支持数据传输的 USB 线。拿不准就拔插对比，消失又出现的那一项就是开发板。

弹窗里找不到串口怎么办？
先确认开发板插在这台电脑上；换一根确定能传数据的 USB 线（只能充电的线插上后看不到任何串口，这是最常见原因）；关闭可能占用串口的 Arduino IDE、串口助手等工具；直连电脑接口，先不经过扩展坞；拔插开发板后重试。串口选择窗口由浏览器提供，所以外观和系统一致。
macOS：串口列表里该选哪一项？
选 “USB JTAG/serial debug unit”，底层设备名是 /dev/cu.usbmodem*（ESP32-C3 内置 USB 串口）或 /dev/cu.usbserial-*（外接 CP210x / CH340 转串口芯片），授权过的条目可能带 “- Paired / 已配对”，括号里的数字每台电脑不同。不要选 cu.Bluetooth-Incoming-Port（Mac 自带的蓝牙虚拟串口）、cu.debug-console、cu.wlan-debug，它们和开发板无关。请使用支持数据传输的 USB 线。
Windows：串口列表里该选哪一项？
选插上开发板后新出现的 COM 口，常见显示为 “USB JTAG/serial debug unit (COMx)” 或 “USB 串行设备 / USB Serial Device (COMx)”；CP210x 板显示 “Silicon Labs CP210x USB to UART Bridge (COMx)”，CH340 板显示 “USB-SERIAL CH340 (COMx)”。COM 后面的数字每台电脑不同，最可靠的识别方法是拔插前后对比列表。不要选一直都在的 “通信端口 (COM1)” 或 “蓝牙链接上的标准串行”。CH340 板若完全不出现，需要先安装 CH340 驱动。请使用支持数据传输的 USB 线。

自动连接说明

刷新自动连接：页面加载后调用 navigator.bluetooth.getDevices() 取回本站点已授权的设备，按「上次连接的设备 → 其他已授权设备」顺序尝试，支持 watchAdvertisements 的浏览器会先确认设备在附近再连接。

多标签页同步：任一标签页连上设备后，会通过 BroadcastChannel 通知其他标签页；其他标签页会用同一授权自动建立自己的 GATT 连接（Chrome 会复用同一条蓝牙链路）。若无法直连，则以「镜像」方式显示该标签页转发的实时数值。

浏览器限制：首次使用必须手动点「扫描并连接设备」授予权限；网页无法静默扫描未授权设备。部分 Chrome 版本需开启 chrome://flags/#enable-web-bluetooth-new-permissions-backend 才能在刷新后保留授权。手动点「断开」后不会自动重连。

    01
    FIRMWARE

    烧录或更新固件

    普通用户统一使用电脑端网页烧录。打开项目 GitHub Pages，用桌面版 Chrome 或 Edge 一键完成，不需要安装命令行工具。

    自建入口：https://mengen-ink.github.io/bikepower-c/。Pages 临时不可用时，使用备用烧录入口。

    网页端烧录 · 七步流程

    1. 用桌面版 Chrome 或 Edge 打开项目 GitHub Pages 或备用入口。

    2. 用支持数据传输的 USB 线把开发板连接到电脑。

    3. 选择 通用 ESP32-C3 或 M5Stamp C3，核对版本和文件名。

    4. 点击「连接串口并刷写」。

    5. 在浏览器弹出的串口列表里选择开发板端口。

    6. 按网页提示确认并等待烧录完成。

    7. 重新上电或按一下 RST 复位键，设备启动。

    找不到设备？优先更换一根支持数据传输的 USB 线。关闭 Arduino IDE、串口助手等占用串口的程序；拔插开发板后再试一次。
    02
    CONNECT

    上电后连接骑行 App

    默认蓝牙名称为 BikePower。上电后 LED 慢闪即进入广播状态，骑行 App 可以立刻搜到。

    1. 用 USB 或稳定 5V 电源给设备上电。

    2. 等待设备启动，LED 通常进入慢闪。

    3. 打开骑行 App，进入添加设备或蓝牙设备搜索页面。

    4. 搜索并连接 BikePower。

    5. 连接成功后，App 会收到功率、踏频、心率和训练机数据。

    如果 App 支持多种设备类型，优先按功率计、心率计、踏频传感器或智能训练台搜索。
    03
    BUTTON

    按钮日常操作

    设备上只有一个按钮。短按用于调功，长按配合二次确认进入 WiFi 配网。

    操作效果适用场景
    短按一次功率减少一个步进骑行中临时降低强度
    按住约 0.5s 后继续按住持续增加功率骑行中快速升强度
    长按超过 2s 后松开进入配网确认窗口准备修改网页设置
    确认窗口内再按一次打开 WiFi 配网页修改功率、设备名、LED 等配置
    确认窗口内不再操作自动取消防误触
    按钮调功步进默认 20 W，可在网页「设置 → 配置设备 → 物理按钮」里修改为 5-50 W。
    04
    WIFI

    进入 WiFi 配网页

    BikePower C 不会开机自动打开 WiFi。只有手动长按并二次确认后，才会进入配网。

    1. 长按按钮至少 2s 后松开。

    2. 看到 LED 进入快闪确认状态。

    3. 在确认窗口内再按一次按钮。

    4. 手机连接热点 BikePower-XXXXXX，密码 12345678。

    5. 浏览器访问 http://192.168.4.1。

    6. 修改配置后点击「保存配置」或「保存设置」。

    7. 不再修改时点击「保存并关闭 WiFi」，等待约 5s 后热点关闭。

    配网期间 BLE 会保持工作，骑行 App 通常可以继续接收数据。手机提示「此网络无互联网」是正常现象，继续保持连接即可。
    05
    CYCLING

    首页 · 骑行模式

    首页顶部可以在骑行与跑步之间切换。骑行模式向骑行 App 广播功率、踏频、心率与训练机数据。

    操作顺序

    1. 选择顶部模式：固定模式手动设定，配速机器人按体重和 W/kg 自动换算。

    2. 固定模式下，直接修改固定功率、固定踏频、目标心率。

    3. 用每张卡片下方的 − / + 调整浮动范围。

    4. 如需固定心率，打开「锁定心率」；关闭后心率会跟随功率算法变化。

    5. 配速机器人模式下选择档位；选择「自定义」后可改昵称和 W/kg 上下限。

    6. 点击「保存配置」立即生效。修改完成后点击「保存并关闭 WiFi」退出配网。

    模式建议：想明确固定在某个瓦数附近 → 固定模式；想按体重模拟跟骑强度 → 配速机器人；使用训练 App 的 ERG 课程 → 让 App 下发目标功率，手动功率可能暂不生效。
    06
    RUNNING

    首页 · 跑步模式

    跑步模式向 Zwift、MyWhoosh 等跑步入口广播跑步速度、步频和心率。

    1. 点击首页顶部「跑步」。

    2. 选择固定配速或自定义模板；固定配速可点击 3:00 到 7:00 的常用按钮。

    3. 自定义模板可修改名称和快 / 慢配速区间，固件会在区间内生成自然变化。

    4. 设置步频和步频浮动。

    5. 设置目标心率；联动模式按跑步强度变化，锁死模式按填写值输出。

    6. 点击「保存配置」，固件会按跑步模式重建 BLE 广播。

    LED

    设置 · LED 指示

    给待连接、已连接、配网中、二次确认、异常 5 种状态分别配置灯效和颜色。

    状态含义
    待连接设备正在 BLE 广播，等待 App 连接
    已连接App 已连接设备
    配网中WiFi 热点已打开，可访问网页
    二次确认长按后等待再次按键确认
    异常设备检测到异常状态
    灯效可选关闭、常亮、慢闪、快闪、双闪、呼吸。普通单色 LED 只体现亮灭节奏，RGB 板同时体现颜色。

    静默模式

    1. 夜骑、卧室或不想被灯光打扰时，打开静默模式，所有状态都灭灯。

    2. 需要重新设置颜色和闪烁方式时，先关闭静默模式。

    3. 修改后点击「保存设置」。

    4. 确认模板别名后保存模板。

    5. 需要使用时，点击「复制到本设备」。

    6. 返回配置设备页，确认名称变化后点击「保存设置」。

    13
    SAVE

    保存和退出配网

    两个保存按钮对应不同生命周期。推荐的日常保存顺序。

    按钮作用
    保存配置 / 保存设置保存当前页面配置，WiFi 继续保持打开
    保存并关闭 WiFi保存首页配置，并在约 5s 后关闭热点

    推荐流程

    1. 先在首页和设置页完成所有修改。

    2. 每个页面改完后点击对应的保存按钮。

    3. 最后回到首页，点击「保存并关闭 WiFi」。

    4. 手机会断开 BikePower-XXXXXX 热点，设备回到日常 BLE 使用状态。

    如果只关闭浏览器或直接断电，最后一次未保存的修改可能不会保留。
    14
    TROUBLESHOOT

    常见问题

    7 个最常被问到的问题与解决方向。

    Q01搜不到 BLE 设备
    先确认设备已上电且 LED 有状态变化。然后在骑行 App 里重新扫描 BikePower。如果仍搜不到，重启 App 或重新给设备上电。
    Q02进不了 WiFi 配网页
    确认已经完成两步按钮操作：长按超过 2s，松开后再按一次确认。然后连接 BikePower-XXXXXX 热点，手动访问 192.168.4.1。
    Q03手机提示无互联网
    这是正常现象。BikePower 的 WiFi 只用于本地配置，不提供外网。
    Q04保存后 App 没变化
    先确认点的是「保存配置」或「保存设置」。如果改的是蓝牙名称，部分 App 需要断开后重新扫描才能看到新名称。
    Q05功率变化不符合预期
    先看当前模式。固定模式按手动设置输出；配速机器人按体重和 W/kg 算功率；ERG 模式可能由训练 App 接管目标功率。
    Q06LED 选项不见了
    检查是否打开了静默模式。静默模式开启后，普通状态的灯效和颜色选择会隐藏；关闭静默模式后可继续编辑。
    Q07如何更新固件
    打开项目 GitHub Pages，按第 1 节的网页烧录流程重新烧录；Pages 临时不可用时使用备用烧录入口。

    记住这 4 步

    把设备日常使用压缩成 4 个动作：上电连接、长按进配网、修改保存、保存并关闭。

    01
    上电连接
    给设备通电，等待 LED 慢闪，在骑行 App 内搜索并连接 BikePower。
    02
    长按进配网
    长按按钮超过 2 秒松开，看到快闪后再按一次，手机连接 BikePower-XXXXXX 热点并访问 192.168.4.1。
    03
    修改保存
    在网页里修改首页或设置页参数，每页改完点击「保存配置」或「保存设置」。
    04
    保存并关闭
    回到首页点击「保存并关闭 WiFi」，约 5 秒后热点关闭，回到日常 BLE 使用。

    WEB TOOLS

    网页工具台 · 设备比对与模板写入

    想让开发板在骑行 App 里显示得像另一台真实设备？用「设备比对」读取参考设备的身份信息，复制为模板，再一键写入开发板。

    进站连接：蓝牙是主连接，USB 串口只用于刷写

    打开工具台会先弹出蓝牙连接门（类似钱包网站进站先连接钱包）：点「连接蓝牙设备」并在浏览器弹窗里选中设备即可。本站点授权过的设备会直接列出，点一下免弹窗直连；刷新页面时会自动重连上次的设备。连接成功后默认打开本手册，并在页面右上角常驻连接胶囊：绿点 = 已连接，红点 = 已断开（点击可一键重连），黄点 = 连接中或镜像其他标签页。点胶囊可查看厂商 / 型号 / 固件，切换设备、断开或直接写入身份。

    USB 数据线与 Web Serial 只在「固件刷写」页使用；刷完后拔掉数据线也没关系，其余所有工具都走蓝牙。不想马上连接可点「先看手册，稍后连接」，本次会话内不再弹出。

    页面如何自动识别开发板

    连接后网页会枚举设备的 GATT 服务，不看设备名（设备名可以被改成任何值），只看是否提供 BikePower 私有服务：

    识别结果判定依据可以做什么
    BikePower 开发板 · 可写入提供配置服务 7a5a0000，且包含身份覆盖特征 7a5a0008作为写入目标，接收模板里的设备名、厂商、型号、序列号、硬件 / 固件 / 软件版本
    BikePower 开发板 · 旧固件只有配置服务 7a5a0000，没有 7a5a0008可以改设备名和参数；身份写入需先到「固件刷写」升级
    参考骑行设备没有 BikePower 配置服务的功率计、心率带、骑行台等只读：比对字段、复制为模板（不会向它写入任何数据）

    复制模板并写入 · 五步

    1. 打开「设备比对」，点「添加设备」连接开发板（已在实时监控里连着的，点「加入监控中的设备」即可）。卡片会显示橙色 BikePower 开发板 · 可写入。

    2. 再点「添加设备」连接参考骑行设备，卡片显示紫色 参考骑行设备，下方表格会标出两者差异。

    3. 在参考设备卡片上点「复制为模板 → 写入开发板」，模板会保存在浏览器里并打开写入面板，目标开发板已自动选好。

    4. 核对或修改字段（每项最多 31 字节，设备名最多 23 字节），点「写入开发板」并确认。

    5. 页面会回读校验并刷新卡片。骑行 App 若仍显示旧信息，在 App 里删除设备后重新搜索。

    恢复原样：在写入面板点「恢复内置值」，开发板的设备信息服务会回到固件内置的厂商 / 型号 / 版本，设备名不受影响。
