准备一根能传数据的 USB 线，按下面三步操作。整个过程都在浏览器里完成，不需要安装命令行工具。

约 2 分钟写入期间别拔线
STEP 1 / 插线把开发板接到电脑

必须使用支持数据传输的 USB 线。只有充电功能的线会让电脑看不到串口。

STEP 2 / 选串口点击下方按钮并选择设备

弹窗里通常会看到 USB Serial、CP210x、CH34x 或 JTAG/Serial。只有一个选项时直接选择即可。

STEP 3 / 等完成保持页面可见，不要拔线

出现 Installing 或 Wrapping up 都是正常过程；看到 Installation complete 才算完成。

多设备一比一比对

怎么用

依次点击「添加设备」连接多台蓝牙设备，系统会自动比对各设备的信息字段和 GATT 服务列表。黄色背景表示该字段在设备间存在差异，绿色表示一致。点击设备卡片中的「复制为模板」可将该设备信息保存为模板。
